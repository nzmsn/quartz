# 古原生代
**古原生代**（Paleoproterozoic（Era））は、原生代の最初の時代で、25～16億年前である[^kiyokawa2024paleoproterozoic]。

前の時代は[[新太古代]]（太古代）、次の時代は[[中原生代]]。

# 地形
プルーム活動が盛んで、巨大火山区や巨大岩脈が残っている[^kiyokawa2024paleoproterozoic]。

18～14億年前にヌーナ大陸が形成された[^kiyokawa2024paleoproterozoic]。

# 大気
24.5億年前に大酸化事変が発生した[^kiyokawa2024paleoproterozoic]。

23～22億年前、ヒューロニアン氷期に全球凍結となった[^kiyokawa2024paleoproterozoic]。

21～18億年前後に大気酸素濃度が減少した[^kiyokawa2024paleoproterozoic]。

# 海洋
海底ではシアノバクテリアの光合成で酸素が供給されている[^kiyokawa2024paleoproterozoic]。海底に沈殿したバクテリアが酸素吸収して海洋底がヘドロ状態となった[^kiyokawa2024paleoproterozoic]。

18億年前以降、鉄に富む還元的海洋となり、地域的に硫化水素富む強還元的部分が形成された[^kiyokawa2024paleoproterozoic]。。

# 生物
海洋表層にシアノバクテリアやストロマトライトが大繁茂した。海底に沈殿したバクテリアが酸素を吸収して海洋底がヘドロ状態となった[^kiyokawa2024paleoproterozoic]。

21億年前以降、大型多細胞生物や真核生物が出現した[^kiyokawa2024paleoproterozoic]。

# 古原生界
ルーム活動による巨大火山岩、巨大岩脈が残る[^kiyokawa2024paleoproterozoic]。

縞状鉄鉱層が25億年前・18億年前に沈殿した。18～8億年まで大規模縞状鉄鋼層は見つかっていない[^kiyokawa2024paleoproterozoic]。


[^kiyokawa2024paleoproterozoic]: 清川昌一(2024)「新太古代」『最新 地学事典』地学団体研究会編、平凡社。
