# 原太古代
**原太古代**（Eoarchean）は、地球最古岩石アカスタ片麻岩形成（40億年前）から南ア・豪州の緑色岩帯形成（36億年前）以前の時代である[^1]。

原太古代より前の時代は[[冥王代]]である。

# 天体
月研究より、38億年前まで後期隕石重爆撃機があったことが判明している[^1]。

# 地形
岩石記録より、花崗岩質大陸地殻の存在が確認できる[^1]。大陸地殻は[[冥王代#冥王代ジルコン|冥王代ジルコン]]からも存在が示唆されている。

# 生物
生物起源と思われる石墨が見つかっている[^1]。

# 遺物
発見される岩石は基本的に変成岩である。海洋性化学沈殿岩、砕屑性堆積岩、苦鉄質・超苦鉄質溶岩などに由来する。生物起源と思われる石墨も見つかっている[^1]。

主な岩石として、地球上最古の[[#アカスタ片麻岩|アカスタ片麻岩]]の他、サグレック岩体、ヌギアギツック表成岩体、イスア表成岩体、ナピア岩体などがある[^1]。

## アカスタ片麻岩
**アカスタ片麻岩**（Acasta gneiss）はカナダ楯状地スレーブ区西端アカスタ湖周辺に分布する原生代初期の片麻岩である。主にトーナル岩質，角閃岩質および花崗岩質片麻岩からなる[^2]。

地球上最古の岩石で年代は40億年前から35億年前である。アカスタ片麻岩の年代が冥王代と原太古代の区分となっている[^1]。

[^1]: 清川昌一・小宮剛「原太古代」『最新 地学事典』

[^2]: 有馬眞「原太古代」『最新 地学事典』
