# 古太古代
**古太古代**（Paleoarchean）は36億名年前から32億年前の時代[^1]。前の時代は[[原太古代]]。

# 地形
古太古代には地球上最初の超大陸[[#バールバーラ|バールバーラ]]があったと推定されている[^1]。

チャート岩脈より海底熱水活動が示唆されている[^1]。

花崗岩緑色岩帯のドーム・沈降構造より、プルームテクトニクスの可能性が指摘されている[^1]。

# バールバーラ
古太古代には、地球上最初の超大陸である**バールバーラ超大陸**（Barlbara Supercontinent）があったとされる[^1][^2]。1996年に提唱された[^2]。

バールバーラは現在豪州西部のピルバラクラトン、南アのカプバールクラトンが一体化した大陸である[^1][^2]。大きさは、当時マントル対流規模より、現在の北米大陸くらい[^2]。

20.45億年前のブッシュフェルト複合岩体貫入、20.25億年前のフレデフォート衝突が、カプバールにあってもピルバラにないのでそれ以前に分離したとされる[^2]。
# 古太古界
古太古代の岩石を**古太古界**という。ピルバラクラトン、カプバールクラトンの緑色岩帯には、柱状玄武岩や層状チャートが分布する。、花崗岩緑色岩帯に、プルームテクトニクスの可能性を示唆するドーム・沈降構造が見られる[^1]。

[^1]: 清川昌一「古太古代」『最新 地学事典』

[^2]: 清川昌一「バールバーラ超大陸」『最新 地学事典』
